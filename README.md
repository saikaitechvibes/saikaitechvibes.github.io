# azsearch.github.io
Azure Cognitive / AI Search

This repository demonstrates how to build intelligent search solutions using Microsoft Azure AI Search (formerly Azure Cognitive Search). Azure AI Search provides cloud-based indexing, full-text search, semantic search, vector search, and AI-powered enrichment capabilities for applications that need fast and relevant access to structured and unstructured data.

Key Capabilities:
  🔎 Full-text and semantic search
  🧠 AI-powered search and relevance ranking
  🔢 Vector search for similarity and semantic retrieval
  📄 Indexing and enrichment of documents and other data sources
  🤖 Integration with Azure OpenAI for Retrieval-Augmented Generation (RAG)
  ☁️ Scalable, managed search infrastructure on Azure

**Use Cases:** Common applications include enterprise document search, knowledge bases, RAG-based AI assistants, product search, and intelligent content discovery.

**Note:** Azure AI Search was previously known as Azure Cognitive Search.
